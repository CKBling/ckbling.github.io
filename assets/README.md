# Site assets

- `images/`: owner-supplied portrait and Yonsei University emblem (original files).
- `documents/`: local archival copy of the CV. Website CV links use the owner's Google Drive URL.
- `icons.svg`: local SVG symbols for profile links, email, location, and CV.
- `site.css`, `site.js`, `mark.svg`: page styling, optional image fallbacks, and favicon.

The Yonsei emblem is displayed through a CSS viewport to omit surrounding white
space; the supplied original is preserved. Two identical CV copies were consolidated.
Google Scholar is explicitly a name search until the owner supplies a verified profile URL.
