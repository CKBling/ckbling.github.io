# Publication thumbnails

Add your image or GIF using the exact name below. Supported formats are `.gif`, `.webp`, `.png`, `.jpg`, and `.jpeg`; the page detects the available extension automatically. Keep the `.svg` files in place as fallbacks.

```text
computer-vision/
  qwerty
  halo
  m2m-reg
  disentangling
  cobra
  ct2mri
clinical/
  amyloid-parcellation
  pet-quantification
  pet-denoising
  centiloid
```

For example, save a GIF at `computer-vision/qwerty.gif` or a PNG at `clinical/centiloid.png`. No page edits are needed; the English and Korean pages use the same image mapping.
